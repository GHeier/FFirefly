# Category System Summary

## Overview

The category system now supports **hierarchical dispatching** with:
- **Category** → **Calculation** → **Method** → **File**

This three-level structure allows fine-grained control over which implementation to use based on config variables.

## Structure

### `categories.py`
Master definition file with three-level hierarchy:

```python
CATEGORIES = {
    "category_name": {
        "calculation_name": {
            "method_name": "filename.ext",  # Specific method
            None: "filename.ext",           # No method dispatch needed
        }
    }
}
```

**File extensions:**
- `.cpp` → Direct C++ function call
- `.py` → Python via `call_python_func()`
- `.jl` → Julia via `call_julia_func()`

## Generated Code

### Node Files (`archive/<category>/node.cpp`)

Generates dispatcher code with method-level branching:

**Without methods:**
```cpp
if (calculation == "fs") {
    fs();
}
```

**With methods:**
```cpp
else if (calculation == "dos") {
    if (method == "libtetrabz") {
        dos_libtetrabz();
    }
    else if (method == "python") {
        dos_python_impl();
    }
    else
        cout << "method \"" << method << "\" not recognized for calculation dos" << endl;
}
```

## Usage

### Running the Generators

```bash
cd /home/g/Research/FFirefly/src
python config/categories.py
```

**Outputs:**
1. `archive/main_sections.txt` - Code sections for main.c
2. `archive/<category>/node.cpp` - Category wrappers
3. `archive/<category>/node.hpp` - Category headers
4. Stub implementation files (only if they don't exist)

### Adding a New Calculation

1. **Edit `categories.py`:**
```python
"hamiltonian": {
    "new_calc": {
        "method1": "new_calc_m1.cpp",
        "method2": "new_calc_m2.py",
    },
}
```

2. **Run generator:**
```bash
python config/categories.py
```

3. **Copy generated node files:**
```bash
cp config/categories/archive/hamiltonian/node.* hamiltonian/
```

4. **Implement the stub files** created in your category directory

### Adding a Method to Existing Calculation

1. **Edit `categories.py`:**
```python
"dos": {
    "libtetrabz": "dos_tetrabz.cpp",
    "python": "dos_python.py",
    "new_method": "dos_new.jl",  # Add this
},
```

2. **Regenerate and copy:**
```bash
python config/categories.py
cp config/categories/archive/hamiltonian/node.* hamiltonian/
```

3. **Implement `dos_new.jl`**

## Notes

- **Multiple calculations, one file**: Multiple calculations can reference the same `.cpp` file (e.g., all superconductor calculations use `superconductor.cpp`)
- **Function names**: For C++, function name matches calculation name (not filename)
- **Archive folder**: Generated code goes to `archive/` (excluded from build) for review before copying
- **No overwrites**: Stub generator skips existing files - safe to re-run
- **Julia module names**: Auto-generated in TitleCase from filename (`response_ir.jl` → `ResponseIr`)
